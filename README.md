### What I've built

| Project | What it does | Built with |
| --- | --- | --- |
| **[Sentio](https://github.com/karansingh1939/Sentio-An-Emotion-Aware-Tutor)** | A local AI study tutor that answers only from your own notes, cites the slide or page, and refuses when the notes don't cover the question. Turns the same notes into quizzes and spaced-repetition flashcards. | Python, FastAPI, LangGraph, Ollama, Qdrant, SQLite |
| **[Goldy Automobiles ERP](https://github.com/karansingh1939/goldy-automobiles-erp)** | An offline-first Windows desktop app for a car repair workshop: job cards, spare-parts inventory, purchasing, billing and GST reports on a single laptop. | Electron, React, Node.js, Express, SQLite |
| **[LocalCode Atlas](https://github.com/karansingh1939/localcode-atlas)** | A VS Code extension that finds code by meaning instead of keywords. The index and the model run on your machine, so your code never leaves it. | TypeScript, Python, SQLite, NumPy, Ollama |
